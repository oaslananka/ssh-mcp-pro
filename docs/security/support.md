# ssh-mcp-pro Help and Support

Need help connecting ChatGPT, Claude or another MCP client, enrolling a device, or understanding access permissions? This is the public support page for ssh-mcp-pro.

## Get help

- Open a support question or report a reproducible problem at https://github.com/oaslananka/ssh-mcp-pro/issues .
- Browse setup and troubleshooting guides at https://oaslananka.github.io/ssh-mcp-pro/ .
- For security-sensitive reports, use private disclosure at https://github.com/oaslananka/ssh-mcp-pro/security/advisories/new .

## Before reporting a problem

Share the operating system, application version, the client and action you were trying, and any non-sensitive error message. For sign-in problems, mention which provider you selected without sharing its credentials. Do not include SSH private keys, passwords, OAuth tokens, API keys, screenshots containing secrets, or private host details in public issues.

## Connection and access

Your device must be enrolled in the same account and connected to the service. Tools honor each device's local access policy. You can disconnect AI clients or remove enrolled devices in your Cloud workspace at https://ssh-mcp-pro.oaslananka.dev/dashboard .

## Data or account requests

For privacy and account-data questions, see https://ssh-mcp-pro.oaslananka.dev/privacy . Public GitHub Issues are not suitable for sending sensitive personal information; use private security disclosure for sensitive security issues.

This service is community-maintained open-source software. No guaranteed response time is offered.
